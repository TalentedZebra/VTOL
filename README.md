# VTOL

A static, GitHub-Pages-ready site for a tilt-rotor tricopter VTOL project: hover on three motors, cruise on a fixed wing.

- `index.html` &mdash; the build manual: a 10-phase pipeline from foundations through flight test, with checklists (progress saved locally in your browser), a budget table, and a resource library.
- `research/` &mdash; Research & Principles: the aerodynamics, propulsion physics, control theory, and structural principles behind the build, written with real citations.
- `assets/` &mdash; shared styles (`styles.css`), the checklist progress tracker (`progress.js`), and site-wide additions (`site.css`).
